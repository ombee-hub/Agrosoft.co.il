Accessibility Statement

Accessibility Policy

We view customers with disabilities as equal-right customers, entitled to full accessibility.

We operate in accordance with the Equal Rights for Persons with Disabilities Law, and our website has been made accessible accordingly.

This section of the website was written to inform you how you can enjoy the accessibility features of the site.

Our goal is to provide equal and accessible service to every customer, with or without a disability.

This website complies with the requirements of the Equal Rights for Persons with Disabilities Regulations (Accessibility Adjustments for Service), 2013.

The site is also adapted for display on popular browsers and for mobile phone use.

Accessibility Feature Guidelines

The website is supported by popular browsers in their most up-to-date versions.

The website supports standard keyboard navigation using arrow keys, Enter, and Esc to exit menus and dialogs.

Accessibility Plugin

This website includes an accessibility plugin that assists in making the site accessible for people with disabilities:

  • A button displaying the accessibility options
  • Clicking the accessibility button opens the accessibility menu
  • Clicking the accessibility button again closes the menu
  • Black & white mode for color blind users
  • High contrast mode
  • A button that clearly highlights all links on the site
  • Increase font size
  • Decrease font size

Enlarging the Display

Users who have difficulty seeing and wish to enlarge the display can do so by pressing Ctrl and + simultaneously. Each press will enlarge the display further.

To reduce the display, press Ctrl and - simultaneously.

Keyboard Navigation

Pressing Tab repeatedly will move between the different links on the page.

Pressing Shift + Tab will return the cursor to the previous link.

Pressing Enter will activate the selected link.

F11 will maximize the screen – pressing again will restore it.

The Space bar will scroll the page down.
